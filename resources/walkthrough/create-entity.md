# Create Your First Entity

Every entity — Character, Location, Faction, Object, or Concept — starts
from a "New \<Type\>" command:

- Command Palette → **LoreFountain: New Character**
- Or the **+** button next to a category in the World view

Creation only ever asks for a name. Everything else is a plain Markdown
file you can fill in at your own pace, through the Story Card form or by
editing the file directly.
