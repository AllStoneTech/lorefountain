# Link It in a Script

LoreFountain recognizes an entity's name (or any alias) anywhere it
appears in a `.fountain` script — no special syntax required:

- As a character cue
- Inside an action line
- Wrapped in `[[double brackets]]` for an explicit, deliberate link

Hover over any recognized mention to preview that entity's Story Card.
Every mention also becomes a backlink, visible from the entity's own file.
