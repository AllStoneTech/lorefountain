# world/

The world of *The Conjure Woman*: one file per entity — the frame cast, each tale's cast, places, groups, objects, concepts, and season arcs. `OVERVIEW.md` holds the title, pitch, tone, and genre.

Subfolders: `glossary/` (conjure terms, dialect, period words), `notes/` (open adaptation questions), `timeline/` (in-world events).

AI agents: see `agents/world-builder.md`.
