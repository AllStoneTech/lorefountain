# world/timeline/

In-world events, one file each. Tale events are anchored to the episode that depicts them and dated only by what the book says ("before the war"). The seven frame events, set after the war, carry a `chronological_order` of 101–107; the book doesn't fix the order between tales, so none is invented.

See `agents/world-builder.md` for the format.
