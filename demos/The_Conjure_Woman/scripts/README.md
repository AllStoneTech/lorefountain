# scripts/

Season 01 of *The Conjure Woman*: seven self-contained half-hour episodes, one per tale in Chesnutt's book, in standard Fountain. Each opens and closes with [[Uncle Julius McAdoo]] addressing the camera, then moves through a frame scene, the tale, and a twist back in the frame.

Scripts use the `SFX:`, `MUSIC:`, and `AMB:` cue convention for tone. Dialogue preserves the source's dialect and period language, including slurs (see the README's content note).

Use **"New Script"** to add episodes; it assigns `Order` and a permanent `Production Code`. AI agents: see `agents/script-writer.md`.
