# imports/

Your own existing source material — an old story bible, outlines, character sheets, spreadsheets, anything that predates LoreFountain or lives outside it. This is realistically a living folder: put new or revised material here anytime, not just at the start.

**LoreFountain never reads, writes, moves, or deletes anything in this folder automatically**, and an AI working in this project shouldn't touch it unprompted either — it's yours. But you can explicitly ask an AI to work with it in either direction:

- **Bringing material in**: new or revised files here into `world/` — see `agents/initiator.md` at the project root. It's safe to run more than once; it checks what's already modeled before creating anything.
- **Pushing updates back out**: if writing in `world/` or `scripts/` moves canon past what's written here, you can ask an AI to update the relevant document to match. There's no LoreFountain-specific tooling behind that direction — whatever's in here gets edited the same way any AI coding agent edits a file, just aimed at this folder instead.

For this demo, `source-material.md` records where the underlying public-domain novel can be read in full and what this project deliberately did and didn't take from it.
