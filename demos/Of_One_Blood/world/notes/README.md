# world/notes/

A low-stakes scratch space. Free-form Markdown, no required frontmatter, no schema — nothing here is validated or checked. This is where a half-formed idea goes ("what if the ship has a hidden fourth deck") before it's ready to become a real entity.

Nothing outside this project reads these files automatically. When an idea is ready, promote it into a proper file under `world/` (the LoreFountain extension has a "Promote Note to Entity" command that does this for you, carrying the text across).
