# scripts/

Season 01, one `.fountain` file per session — 100% standard Fountain, portable to any other Fountain tool. Any entity or glossary term's name appearing anywhere in a script is recognized and linked automatically.

Unlike a novel or TV adaptation's scripts, these aren't shooting scripts of things that already happened — they're GM prep: pre-written boxed-text narration for key beats, scene structure to run from, and `SFX`/`MUSIC`/`AMB` cues doubling as real session audio planning (ambience and stings a GM could actually cue live, with `MUSIC` cues taking an optional Role/Timing modifier). A parallel `SHOT`/`POSE`/`LIGHT`/`DURATION` convention covers any beat worth a pre-production camera breakdown. Where the party's choices genuinely branch things, that's noted in prose rather than pretending there's only one path.

Use the **"New Script"** command to create additional sessions — it assigns `Order` and a permanent `Production Code` for you.

If you're an AI working in this project, see `agents/script-writer.md` at the project root for the exact conventions.
