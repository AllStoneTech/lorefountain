# world/timeline/

In-world events — one file per event, separate from the entities that take part in them. Each event can carry two independent positions: where it's presented to the table (which session depicts it) and where it falls in the world's own internal chronology.

This project leans on that split hard: the Cael's deep history is chronologically earliest but is only revealed to the party piecemeal, session by session, often long after later events have already been played.

If you're an AI working in this project, see `agents/world-builder.md` at the project root for the exact file format.
