# scripts/

Your `.fountain` scripts — 100% standard Fountain, fully portable to any other Fountain tool (Highland, Fade In, Final Draft import, etc.). Nothing LoreFountain-specific is required to make linking to the world work: any entity or glossary term's name appearing anywhere in a script (a character cue, an action line, dialogue) is recognized and linked automatically.

## One feature, eight sequences

This is a feature film, not a series, but LoreFountain's script structure still fits it: the screenplay lives in one folder, `scripts/Feature Film/`, as eight sequence files (`1x01-the-cistern` through `1x08-the-parting-of-ways`), each in its own subfolder. The eight-sequence structure is a standard way to plan a feature: each sequence runs roughly 12–15 pages, and together they form the three acts.

Read in order, the eight files are the whole screenplay. Split this way, each is a unit you can revise, reorder, or share on its own, and the **Production Code** on each stays fixed even if you reorder the sequences.

If you're an AI working in this project, see `agents/script-writer.md` at the project root for the exact conventions.
