# imports/

A drop-zone for your own existing source material — an old story bible, outlines, character sheets, spreadsheets, anything you're migrating into LoreFountain. Put your files here.

**LoreFountain never reads, writes, moves, or deletes anything in this folder automatically**, and neither should an AI working in this project — it's yours. The only thing that touches this folder is you, or an AI you've explicitly asked to read it (see `agents/initiator.md` at the project root for the one-time migration workflow).
