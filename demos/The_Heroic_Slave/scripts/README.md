# scripts/

Season 01 of *The Heroic Slave*: six radio-play episodes, one `.fountain` file each, 100% standard Fountain and portable to any other Fountain tool. Any entity or glossary term's name appearing anywhere in a script is recognized and linked automatically.

| Code | Title | Novella | Running time |
|---|---|---|---|
| 1x01 | The Pine Woods | Part 1 | ~11 min |
| 1x02 | The Fireside | Part 2, first half | ~16 min |
| 1x03 | The Tree | Part 2, second half | ~14 min |
| 1x04 | The Tavern | Part 3 | ~20 min |
| 1x05 | The Marine Coffee-house | Part 4, first half (+ one dramatized scene) | ~14 min |
| 1x06 | The Creole | Part 4, second half | ~16 min |

Because this is audio, every scene is built from `SFX:`, `MUSIC:` and `AMB:` cues plus parenthetical voice direction, and those cues are extracted into each script's `.cues.json` sidecar (regenerated by the validator; never hand-edit). **Export Cue Sheet** (LoreFountain Pro) turns them into a session cue list for the sound designer. The sound plan lives in `world/notes/the-sound-world.md`.

Use the **"New Script"** command to create additional episodes — it assigns `Order` and a permanent `Production Code` for you. If you're an AI working in this project, see `agents/script-writer.md` for the exact conventions.
