# world/timeline/

In-world events, one file per event, separate from the entities that take part in them. Each event can carry two independent positions: where it's presented to the reader (the chapter's production code) and where it falls in the story's own chronology, since those two orders don't always match.

This novel leans on that split. The oldest event, Cardinal Spada's poisoning in 1498 (`the-spada-cardinals-death.md`), is not told until chapter 18, and the birth and burial of Benedetto in 1817 (`benedetto-is-born-and-buried.md`) is pieced together from chapters 43–45, 67 and 110. Several events are marked `contradicted` because the book gives conflicting dates for them; the full list is in `../notes/continuity-ledger.md`.

If you're an AI working in this project, see `agents/world-builder.md` at the project root for the exact file format.
