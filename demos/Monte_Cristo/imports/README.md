# imports/

Your own existing source material, such as an old story bible, outlines, character sheets or spreadsheets. This is realistically a living folder: put new or revised material here anytime, not just at the start.

**LoreFountain never reads, writes, moves, or deletes anything in this folder automatically**, and an AI working in this project shouldn't touch it unprompted either. But you can explicitly ask an AI to work with it in either direction:

- **Bringing material in**: new or revised files here into `world/`. See `agents/initiator.md` at the project root. It's safe to run more than once.
- **Pushing updates back out**: if writing in `world/` or `scripts/` moves canon past what's written here, you can ask an AI to update the relevant document to match.

For this demo, `the-count-of-monte-cristo.md` is the complete Project Gutenberg text converted to Markdown (license header and footer kept verbatim in its last section), and `source-material.md` records how the manuscript in `scripts/` was made from it and what was and wasn't checked.
